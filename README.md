# Raman Tiwari — Personal Portfolio

A sleek, responsive personal portfolio website showcasing my engineering journey, technical skills, academic milestones, and backend projects.

🔗 **Live Website**: [ramantiw45.github.io/Portfolio](https://ramantiw45.github.io/Portfolio/) *(when GitHub Pages is enabled)*

💼 **LinkedIn**: [linkedin.com/in/ramantiw45](https://www.linkedin.com/in/ramantiw45/)  

---

## ✨ Features

- **Warm Copper & Editorial Aesthetic**: Modern dark-mode palette free of blue tones, featuring tailored warm copper metallic gradients, glassmorphism, and editorial typography (Newsreader & Outfit).
- **Interactive Depth & Parallax**: Cursor-reactive parallax layer on the hero image with floating skill badges.
- **Dynamic Counters & Progress Rings**: Animated stats showcasing academic achievements (9.97 CGPI, 98.11 %ile MHT-CET).
- **Interactive Signature**: Elegant handwriting-style brand signature for Raman.
- **AJAX Contact Form**: FormSubmit integration with client-side regex validation, anti-spam honeypot, sending states, and automatic `mailto:` fallback.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile with custom hamburger navigation and smooth transitions.

---

## 🛠️ Built With

- **HTML5**: Semantic, accessible markup with OpenGraph and SEO tags
- **Vanilla CSS**: Custom design system, CSS variables, glassmorphism cards, fluid animations
- **Vanilla JavaScript (ES6+)**: Intersection Observers, smooth scrolling, interactive counters, and FormSubmit AJAX handling
- **Google Fonts**: Newsreader, Outfit, Plus Jakarta Sans, Lora, Caveat

---

## 🚀 Quick Start / Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/ramantiw45/Portfolio.git
   cd Portfolio
   ```
2. Open `index.html` in any web browser or use a local server:
   ```bash
   npx serve .
   # or
   python -m http.server 3000
   ```
